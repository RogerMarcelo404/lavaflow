# LavaFlow

Sistema web para gestão de lava-jatos e estéticas automotivas, desenvolvido como Projeto Integrador.

Professor: Caio Koch

## Sobre o projeto
O LavaFlow organiza o atendimento do lava-jato, do agendamento ao pagamento, com cálculo automático do preço por porte do veículo e da comissão dos funcionários, controle de pacotes mensais e fechamento de caixa diário.

## Tecnologias
- Python + Django
- HTML, CSS, JavaScript e Bootstrap 5
- PostgreSQL
